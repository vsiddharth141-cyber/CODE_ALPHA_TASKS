CodeAlpha Software Development Internship - Java Tasks
This repository contains the Java programming tasks completed during my internship at CodeAlpha. The projects demonstrate core object-oriented programming (OOP) principles, data structures, and console-based user interface management.

🚀 Tasks Completed
Task 1: Student Grade Tracker
A console-based application designed to manage student records efficiently.

Key Features: Dynamically adds student profiles using ArrayList, implements real-time numerical input validation, and automatically calculates the class average, highest performing student, and lowest performing student.
Task 2: Stock Trading Platform
A simulated market environment allowing users to buy and sell stocks with virtual currency.

Key Features: Tracks active market data and individual portfolio balances using HashMap. Supports real-time balance deductions, share inventory tracking, and dynamic portfolio valuation based on live ticker symbols.
🛠️ Tech Stack
Language: Java (JDK 8+)
Environment: Visual Studio Code (VS Code)
